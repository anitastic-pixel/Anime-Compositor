# D-674: Mercury

B-553, after CycoreFX's CC Mr. Mercury (Simulation): the layer turned into drops of liquid metal from the in point, each born at the producer with the picture's colour there, thrown and falling, swelling in and shrinking out, running together as metaballs and lit by Drizzle's light. Nothing is carried from frame to frame: every frame counts the drops from the in point (document 20). CycoreFX publishes no formula and no settings when added, so the rule and those settings are ours, stated in `tools/mercury_reference.py`. Every expected pixel is `Fixtures/mercury/expected_mercury.json`, written by the tool before this code existed and printed in document 25 as FX-MERCURY-001 to 038. Tolerance 2e-5.
