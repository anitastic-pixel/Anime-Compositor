# P-27: speed audit, ranked by what the owner feels

Measured on 2026-11-03. **Every timing taken today is from a busy machine and is not final**: other lanes' cargo and rustc were running during every run (9 such processes counted during the app build, 3 during the last p16 run). Each has a quiet re-measure row below, marked "to do". Memory counts and frame counts do not depend on the machine being busy.

- Machine: AMD Ryzen 9 9900X (24 threads), NVIDIA GeForce RTX 4070 Ti SUPER on Vulkan, Windows 11 Education 10.0.26300.
- Build: release, commit 7ccfbdcd plus the two new measuring files of this audit (`tests/p20_edit_cost.rs`, `tools/p21_page_cost.py`); `CARGO_TARGET_DIR=target/lanes/p27`, `CARGO_INCREMENTAL=0`, `-j 4`.
- Projects: the reference shot (`verification/B-08a_project.json`, 4 layers), and the same shot with its layer 2 (a cel layer with a full exposure sheet) copied to 50 and to 200 layers, each copy with 25 position keys; the largest has 5,000 keys and is 7.9 MB as a saved file.
- p20: median of 5 to 51 runs (about 3 s a row; run counts printed). p21: one launch per project of a background copy of the app (`ANIME_COMPOSITOR_BACKGROUND=1`, its own WebView2 profile, nothing on screen, the owner's profile not touched), 7 runs each, medians.

## Owner summary

The slowest thing you will feel is editing a big project. With 200 layers, one small change (a rename, a typed number, an undo) takes about 1.7 seconds to show, against 14 milliseconds for the reference shot, because after every change the program sends the whole project to the window and the window redraws every panel. While that text is being written, frames stop. Moving the timeline zoom takes about half a second at that size. Any change, even a rename, also throws away every frame made ahead, so RAM preview starts again. Each undo step keeps a full copy of the project, about 1.7 MB at 200 layers, with no limit. Autosave briefly holds up frames every two minutes.

Six fixes are proposed, D-1115 to D-1120. None of them changes a picture. Each is checked byte for byte against what the program draws today. Copying the project, which an earlier audit suspected, was measured and costs under a millisecond, so no fix is proposed for it. All timings are from a busy machine and will be measured again on a quiet one.
