# D-734: Replace layer source (Ctrl+Alt+/)

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

After Effects' Replace Layer Source. Select a layer, click a picture, sequence or sound in the Project panel, and press Ctrl+Alt+/ (or Layer > Replace layer source): the layer shows the new item and keeps its name, keys, effects, transform, timing and Sheet. A drawing layer takes a picture or a sequence and a sound layer a sound file; anything else is refused with a sentence, and nothing changes.

The project is `verification/B-08a_project.json` with a Tint added to layer 1 and a sound file added to the Project panel. The third row compares the whole layer before and after, apart from its source.

## What to look at

- **A drawing number the new sequence does not have** is not refused: the Sheet keeps its numbers, and a frame showing a number the new sequence lacks is reported as a missing drawing, as it is anywhere else.
- **A composition layer's source** is not replaced by this; that is left for later.
