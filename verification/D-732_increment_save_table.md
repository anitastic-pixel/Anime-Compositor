# D-732: Increment and Save (Ctrl+Alt+Shift+S)

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

After Effects' File > Increment and Save: the project is saved under its name with the next version number, and the window carries on with that new file. A name with no `_v` number gains `_v002`; a number already used by a file in the folder is skipped, so an older version is never written over. Under the hood it is Save As to a name the window picks, so everything Save As promises (media paths kept, unknown data kept) holds here too.
