# D-735: the Keyboard shortcuts window (W-37)

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

W-37 from `design/W-37_shortcuts.html`. The bottom strip's long line of key hints is now a Keyboard shortcuts button; the Help menu and the command finder open the same window. It lists every command finder line in areas (Project, Edit, New layers, Layers, Time, Keys, Properties, Timeline, Viewer, Tools, Finding, Sheet) with its keys, searches by words or by a pressed key, changes any line's keys (one that had none can be given some), names a clash before anything changes, and resets one line or all of them. Changes are kept on this computer, never in the project. Print or save as PDF prints the list.

The window is page code only, so the rows pin the page text each promise rests on; the last rows read the command finder's lines for the defaults. No default key changed. Pictures of the window, taken from the page in a browser with no project open, and the printed list as a PDF, are in `verification/D-735 pictures/`.

## What was left out

- **Keys that are not command finder lines** (the arrows, A S R T M, the Alt+Shift keys that set a key, the Sheet's and the Sketch board's keys) are named in a clash but cannot be changed.
- **Ctrl+C and Ctrl+V** are shared by several lines and act on what is selected; giving one of those lines new keys does not take Ctrl+C or Ctrl+V away from the others.
- **A changed key does not act while you type in a field or in the Sheet**, unless it uses Ctrl.
- **The areas** are chosen from each line's name; a new command finder line with an unusual name lands in Layers.
