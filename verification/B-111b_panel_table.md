# B-111b: a camera that rides a layer, from the window

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

D-171 decided that the camera can ride a layer, as a layer rides its parent; B-111b built it in the core, checked frame by frame in `verification/B-111_camera_rig_table.md`. This is the window's half: the camera's panel has a Parent list, which sends the request a layer's own Parent list sends, `layer.set_parent`, with `target=camera`. It keeps the camera where it stands on the frame shown, and deleting the layer it rides lets it go where it stands. An audio layer is not offered; the core refuses one, which its table checks.

## What this does not cover

Whether the shot moves as a person expects when the layer under it moves, and whether the list feels right in the hand. That is `verification/B-111_camera_rig_playtest.md`, for a person.
