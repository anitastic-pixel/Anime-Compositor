## What to look at first

The five rows at the top of the table are the important ones. `Fixtures/projects/` holds five project files that were written by hand, before any of this code existed. Each row opens one of them and saves it again, and requires the result to be the same file **byte for byte**.

That one equality is worth more than the rest of the table together. Passing it means nothing was dropped, nothing was reordered, no number was rounded, no accented or Japanese character was mangled, and the records this build cannot use — an effect from a vendor that does not exist, a `work_area` nothing reads, a blob called `opaque_unknown_data` — all came back out exactly as they went in. Failing it names the first line that differs.

## The other file to open

`B-09_saved_after_edit.json` is `Fixtures/projects/unknown_effect_project.json` opened, its one layer renamed, and saved. Open the two side by side. Exactly one line should differ: the layer's name. Everything else, including the effect this build cannot run and the vendor data inside it, should be untouched. If more than one line differs, saving is rewriting parts of the project it was not asked to change.
