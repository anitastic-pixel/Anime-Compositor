# B-787 timing: frames made ahead at rest on the card (D-908), switched on against off

Measured on 2026-10-27 in a quiet slot on the main machine (AMD64 Family 26 Model 68, 24 threads,
Windows, release builds, nothing else building). Each build opened the reference shot (L4: 4
layers; L25: 25 layers) in its own WebView2 profile, and six drags were played on it: move, scale,
mask point, number scrub, time bar, and a mask drag held still part way (maskpause). Six
alternating rounds, two runs a round, so 12 runs a row. Delays in ms from the mouse to the frame
on the screen: median of each run's median, and of each run's 95th percentile.

- **off**: B-787 as on main, both ahead-at-rest switches off (the shipped build).
- **on**: the same build with AHEAD_AT_REST on for the card.
- **before**: main before B-787.

## Result

D-908 stays **PROPOSED and switched off**. Its rule was that "on" must match "off" on every card
drag, held mask included. It does not: with the card at Full on L4, the held mask drag goes from
30 ms to 49 ms (median, every run slower), and on L25 the Draft mask drag goes from 54 to 63 ms
and the Full scale drag from 28 to 39 ms. Other card drags are the same or a little quicker.
The processor rows are the same either way.
