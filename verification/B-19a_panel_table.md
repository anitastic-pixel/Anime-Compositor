# B-19a: a key dragged and typed in the graph

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

B-19a lets a key in the graph editor be dragged up and down as well as along, and lets its frame and value be typed. Both send `keyframe.move` with a `value=` beside each `key=`: the keys move, and each then holds the value given, as one entry to undo. Nothing in the file format or in how a curve is worked out changes.

Every row calls what the window calls, on `Fixtures/projects/cel_holds_project.json`, and reads back what the page is given.

## What this does not cover

The dragging itself, the box drawn around keys, the snapping, the numbered lines, and the zoom and Fit of the values are all in the page and change nothing here. They are `verification/B-19a_graph_playtest.md`, for a person.
