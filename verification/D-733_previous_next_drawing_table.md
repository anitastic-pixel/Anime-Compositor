# D-733: previous and next drawing (Shift+, and Shift+.)

Generated by `app/src/main.rs`, module `editing`. Re-run with `cargo test --workspace`.

OpenToonz's, Harmony's and TVPaint's previous and next drawing. Shift+, sends the playhead to the nearest frame before it where the selected layer's drawing changes; Shift+. to the nearest one after it. A change is a new drawing number on the layer's Sheet column, or the start of a blank; a held frame is not a change. With no drawing layer selected it uses the first column, as the sheet strip does.

The expected frames are worked out by hand from the exposures written in `verification/B-08a_project.json` (layer 1 one drawing, layer 2 on ones, layer 3 on twos, layer 4 on threes with a one-frame drawing at 152 and drawing 11 shown again at 165); a blank is cleared into layer 2 for the test. The rule the page applies is the text pinned in the first row; the rows after apply that rule to the Sheet the window answers the page with.
