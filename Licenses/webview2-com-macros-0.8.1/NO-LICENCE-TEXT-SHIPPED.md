# webview2-com-macros-0.8.1 ships no licence text

`webview2-com-macros-0.8.1` declares its licence in `Cargo.toml`, which `docs/DEPENDENCIES.md` records, and ships no
LICENSE, COPYING, NOTICE or UNLICENSE file for `tools/archive_licenses.py` to copy. Nothing is
missing from this archive; there was nothing to archive.

This file is written by `tools/archive_licenses.py` and says so on purpose. A distribution that has
to reproduce a notice cannot reproduce one the crate never published, and that is a question for a
reviewer rather than something a tool can settle.
