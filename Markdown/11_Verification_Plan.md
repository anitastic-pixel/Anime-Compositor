## Test strategy

Use small numeric fixtures for correctness, representative shots for usability and declared workloads for performance. Keep expected outputs independently derived where possible; an output generated by the implementation under test is not automatically a valid golden reference.

Every fixture stores origin/permission, dimensions, color/alpha interpretation, frame rate, expected result and tolerance. Never use unlicensed anime frames as a redistributable test set. Performance reports include machine, OS, driver, build and cold/warm cache conditions.

## Proposed numeric tolerances

Exact checks: frame count, exposure IDs, serialized values, job status and supported schema round-trip. For float32 normal-over fixtures, begin with absolute channel error at or below 1e-6 on normalized inputs. For an 8-bit output round-trip, allow at most one code value per tested channel where rounding applies.

Blur and resampling need operation-specific numeric and visual thresholds established before optimization. Do not accept a global image similarity score that can hide damaged thin lines. Inspect black/white diagonals, one-pixel lines, saturated edges and transparent borders at full scale.

## Gates

G0 passes when stack experiments demonstrate save safety, alpha correctness and reproducible output. G1 passes all applicable T-01 through T-10, T-15 and T-16, completes W-01 and has no known reproducible project-corruption defect. G2 adds T-11 and T-12 plus W-04. T-13/T-14 become required only for shipped packaging/formats.

For an artist alpha, collect known limitations and recovery instructions and use disposable copies of artwork. A failed correctness test blocks the relevant feature; a missed performance target triggers optimization or a revised supported envelope with documented rationale.

## Evidence record

Each result records test ID, build, fixture version, expected/actual behavior, logs or image diffs, reviewer and disposition. Status starts NOT RUN for every test in this pack. Do not convert a proposed gate into a claimed result.
