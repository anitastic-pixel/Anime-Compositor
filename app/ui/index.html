    Memory

    How much the preview may keep in memory to play faster. Each is a most, not a reservation: what the preview does not use stays free for other programs.

    Drawings and compositions on disk

    The first time the preview unpacks a drawing it keeps a copy on disk, so playing the shot again, even after closing the program, starts sooner. It does the same for a composition shown inside another when the composition is slow to draw, so the outer shot plays without drawing it again until something inside it changes. The copies are the same pixels to the bit, are only for the preview (export always reads the drawings themselves), and are safe to delete at any time. 0 GB turns this off.
